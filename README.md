Gobble Dash — A Turkey's Great Escape: a top-down stealth-escape game in plain browser JavaScript. A turkey dodges the farmer, his dog, a sweeping carving knife and a scorching oven across three stages — farmyard, barn, kitchen — hiding in hay, sprinting on stamina and hopping over obstacles to escape becoming Thanksgiving dinner.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
